Створити команду POST /teams/

Команда для Party-режиму завжди складається рівно з 3 різних гравців. Вкажіть їхні ID (перше поле автоматично підставляє «Мій ID»).

Знайти / редагувати команду GET, PATCH, DELETE /teams/{id}

Склад команди (гравці) не змінюється після створення — лише назва, статус «постійне паті» або повне видалення (якщо команда ще не грала матчів).

Почати матч POST /matches/solo|party/find

Автопошук сам знаходить вільного суперника з найближчим MMR. Право обирати сторону монети (Орел/Решка) автоматично отримує сторона з нижчим MMR.

Сервер сам знайде вільного суперника з найближчим Solo-MMR і одразу створить матч.
Сервер сам знайде вільну команду з найближчим сумарним Party-MMR і одразу створить матч.
